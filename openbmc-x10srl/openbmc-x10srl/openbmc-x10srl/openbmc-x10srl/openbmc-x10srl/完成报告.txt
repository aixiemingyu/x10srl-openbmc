部署流程
════════════════════════════════════════════════════════════════
步骤 1: 环境准备
   └─ 安装编译依赖 (build-essential, python3, git 等)

步骤 2: 获取源码
   ├─ 克隆 OpenBMC: git clone https://github.com/openbmc/openbmc.git
   └─ 复制配置层: cp -r meta-supermicro-x10srl openbmc/

步骤 3: 配置编译
   ├─ 初始化环境: . setup x10srl
   ├─ 添加 Layer
   └─ 配置并行编译

步骤 4: 编译固件
   └─ 执行编译: bitbake obmc-phosphor-image
      (首次编译约 2-4 小时)

步骤 5: 备份原固件
   └─ 运行备份: ./backup-bmc.sh -i <BMC_IP>

步骤 6: 刷写新固件
   └─ 网络刷写: ./flash-firmware.sh -f firmware.mtd -m network -i <BMC_IP>

步骤 7: 测试验证
   ├─ 系统测试: ./test-system.sh
   └─ IPMI 测试: ./test-ipmi.sh <BMC_IP>

快速开始命令
════════════════════════════════════════════════════════════════
# 方式 1: 使用自动部署脚本 (推荐)
cd openbmc-x10srl
./deploy.sh

# 方式 2: 手动步骤
git clone https://github.com/openbmc/openbmc.git
cd openbmc
cp -r /path/to/meta-supermicro-x10srl ./
. setup x10srl
echo 'BBLAYERS += "${BSPDIR}/meta-supermicro-x10srl"' >> conf/bblayers.conf
bitbake obmc-phosphor-image

# 刷写固件
./flash-firmware.sh -f <固件路径> -m network -i <BMC_IP>

# 测试验证
./test-system.sh
./test-ipmi.sh <BMC_IP>
