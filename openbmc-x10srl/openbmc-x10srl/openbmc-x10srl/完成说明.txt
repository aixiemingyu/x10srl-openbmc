📋 **使用流程:**

1️⃣ 运行部署脚本:
   ```bash
   cd openbmc-x10srl
   ./deploy.sh
   ```

2️⃣ 备份原固件:
   ```bash
   ./backup-bmc.sh -i 192.168.1.100
   ```

3️⃣ 刷写新固件:
   ```bash
   ./flash-firmware.sh -f firmware.mtd -m network -i 192.168.1.100
   ```

4️⃣ 测试验证:
   ```bash
   ./test-system.sh
   ./test-ipmi.sh 192.168.1.100
   ```

⚠️ **注意事项:**
- 首次编译需要数小时
- 需要至少 50GB 磁盘空间
- 刷写前务必备份原固件
- 刷写过程中请勿断电
