# X10SRL OpenBMC 适配项目

## 快速开始

1. **安装依赖**
```bash
sudo apt-get install git build-essential python3 gawk wget diffstat unzip
```

2. **克隆 OpenBMC**
```bash
git clone https://github.com/openbmc/openbmc.git
cd openbmc
```

3. **复制配置层**
```bash
cp -r /path/to/meta-supermicro-x10srl ./
```

4. **编译固件**
```bash
./meta-supermicro-x10srl/build.sh
```

详细说明请查看 [README.md](README.md)

## 文件说明

- `meta-supermicro-x10srl/` - OpenBMC 机器层
- `README.md` - 详细文档
- `build.sh` - 快速编译脚本

## 主要特性

✅ ASPEED AST2400 支持
✅ 温度传感器 (LM75)
✅ 电压监控 (ADC)
✅ 风扇控制 (PWM)
✅ IPMI 支持
✅ Web 管理界面
✅ SSH 访问
